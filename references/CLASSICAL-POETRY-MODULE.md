# 古风叙事诗模块

> 目标：为**原创奇幻故事**生成能嵌入章节的短古风诗、题壁诗、临别诗、誓言诗与谶语。它学习古典诗词的形式资源，不模仿任何现代作者或特定小说的独特表达。

## 语料来源与许可

- 数据库：[chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)
- 仓库 README 声明：唐诗、宋诗、宋词等中文古典文集，以 JSON 分发。
- 仓库许可证：MIT（仓库层面）。数据来源于互联网，实际使用时仍应保留来源与许可核验意识。
- 本 Skill 的用法：从古典作品抽取**意象、题材、体式与格律习惯**；不复制长句，不把单首作品改几个字后输出。

## 它能做什么

1. 为章首、碑文、祭文、人物誓言写 4 句或 8 句原创古风短诗。
2. 将章节冲突压缩成一个诗意命题，而不是复述剧情。
3. 用季节、地景、器物、光影、声音等意象建立氛围。
4. 在诗后附一行“叙事功能说明”，供作者决定是否嵌入正文。

它不做什么：

- 不声称“像某位当代作者写的”；
- 不复刻《蛊真人》或任何在世作者的诗句、节奏或标志性措辞；
- 不保证严格平仄。需要严格近体诗时，应另行用韵书/格律工具逐字校验；
- 不将虚构中的权谋或冲突转换为现实操作建议。

## 生成管线

### 1. 提取章节内核

先写一行散文，不带修辞：

> 谁在什么约束下，为何失去或争取了什么；这使他付出了什么代价？

例：

> 守灯人为了保住一城夜航的资格，交出了自己的记忆名册，也失去了唯一能证明清白的证据。

### 2. 选择诗歌功能

| 功能 | 适合承载的内容 | 建议形式 |
| --- | --- | --- |
| 题壁 | 地点历史、规则、警告 | 五言或七言绝句 |
| 临别 | 损失、未竟承诺、关系变化 | 五言绝句或小令式短章 |
| 誓言 | 角色的价值选择 | 四句古风，少用典故 |
| 谶语 | 将来风险的模糊投影 | 两至四句，留一处双义 |
| 战后 | 胜利的代价与局势余波 | 七言绝句或八句短章 |

### 3. 建立意象调色板

每首诗只选 2-4 组意象。不要把“月、剑、血、风、雪、酒、山”全部塞进一首。

| 情绪/功能 | 可选意象方向 | 应避免 |
| --- | --- | --- |
| 压力与期限 | 漏刻、残灯、潮汐、霜痕、城门 | 空泛的“命运”“万古”堆叠 |
| 资源与代价 | 旧券、炉灰、空匣、折秤、裂印 | 解释经济规则的术语 |
| 秘密与误判 | 雾、背影、封泥、未落的信、隔墙灯 | 直接说“阴谋”“算计” |
| 失去与余波 | 断桥、退潮、空席、旧衣、孤钟 | 过量哭诉与形容词 |
| 决心与行动 | 未熄火、远帆、石阶、晨鼓、开门 | 口号式豪言 |

### 4. 选择形式约束

- **五言绝句**：每句 5 字，共 4 句。适合章首、题壁、谶语。
- **七言绝句**：每句 7 字，共 4 句。适合战后、远行、局势变化。
- **四句古风**：每句 5-9 字可变。适合角色誓言，优先语义和节奏。
- **八句短章**：用于一卷结尾；前 4 句写处境，后 4 句写代价/转折。

默认不要强行标注格律名；只在确实完成校验后称为“律诗”或“绝句”。

### 5. 生成与自检

生成后依次检查：

1. 能否在不读故事设定的情况下看出一个处境？
2. 是否只保留一个中心转折？
3. 是否包含直接借用的经典名句或高度相似的连续措辞？若是，重写。
4. 是否出现现代网络语、解释性术语或自造专名？若是，删除或改为意象。
5. 是否与角色的已知选择一致，而非只追求“酷”？

## 标准输入模板

```text
为一部原创奇幻故事写一首中文古风短诗。

诗歌功能：题壁 / 临别 / 誓言 / 谶语 / 战后
形式：五言四句 / 七言四句 / 四句古风 / 八句短章
章节内核：
说话者或出现地点：
必须出现的一个意象：
必须避开的词或意象：
情绪：

限制：
- 只写原创文本；不得模仿、改写或延续任何具体作者或小说。
- 不要引用或拼贴古典诗词名句。
- 诗后用一句话说明它对应的叙事功能，不解释逐句含义。
```

## 原创示例

输入内核：守灯人用证据换取城门继续开放，随后失去洗清冤屈的机会。

形式：五言四句。功能：战后。

> 城阙潮声急，
> 灯寒照旧关。
> 一枚封蜡尽，
> 万户夜舟还。

叙事功能：用“封蜡”与“夜舟”把个人证据的消失和群体得救并置，留下选择的代价。

## 嵌入章节的三种位置

| 位置 | 作用 | 注意点 |
| --- | --- | --- |
| 章首 | 预告本章的压力或主题 | 不剧透具体行动 |
| 场景内 | 作为碑文、歌谣、人物誊写 | 要与地点、职业或制度有关 |
| 章末 | 让余波在行动后停留 | 不替代情节结论 |

## 与本 Skill 的连接

1. 用 `ORIGINAL-STORY-WORKFLOW.md` 的冲突卡写出章节内核。
2. 用本模块将内核压缩为一首原创短诗。
3. 用 `NARRATIVE-STRESS-TEST.md` 检查诗有没有掩盖而非强化因果。
4. 若诗涉及机构、盟友或威慑，再回看 `ACTOR-SYSTEMS.md`，确保它与角色的决策模型一致。

## 4090 的正确位置

当前模块是提示词与检索优先的工作流，**不需要训练 GPU 模型**。

若未来要在 RTX 4090 上做实验，较合理的路径是：选择有明确许可的开源基础模型，使用古典诗词语料做检索/评估或在确认数据权利后进行小规模适配；训练目标应为“原创古风诗生成”，而非模仿某位作者或某部现代小说。训练前需要另行制定数据清单、许可证记录、保留集与相似度评估方案。
