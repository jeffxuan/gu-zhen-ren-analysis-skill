# 行动者与势力：决策模型画布

> 这是针对小说叙事的分析工具，不是现实行为指南。所有“策略”仅用于理解虚构人物如何在资源、权力和信息受限的系统中行动。

## 一页决策画布

为任一人物或势力填写以下七项：

| 字段 | 要回答的问题 |
| --- | --- |
| 目标函数 | 它优先优化生存、权力、资源、秩序、复仇、传承，还是别的东西？ |
| 时间尺度 | 它接受多大的短期损失来换取长期位置？ |
| 关键资源 | 它最缺什么：材料、战力、时间、信息、合法性、盟友或地利？ |
| 硬约束 | 什么代价它不能承受？哪些规则不能直接违反？ |
| 信息集 | 它知道什么、猜测什么、无法确认什么？ |
| 可见信号 | 它如何让对手相信自己的能力、底线或承诺？ |
| 触发条件 | 哪个事件会使它合作、升级、撤退、复仇或转向？ |

不要以“角色聪明/愚蠢”填空。应描述在当前信息和约束下，哪些选项对其来说可行。

## 模型 A：长期选择权导向的行动者

### 观察基础

- `chapter_1` 将重置后的经历转化为早期行动信息。
- `chapter_100` 说明关键能力仍有恢复状态和使用边界。
- `chapter_1200` 呈现通过调整时间、灾劫与资源安排来缓解未来压力。
- `chapter_1500` 呈现以高投入换取分工与产能扩张。

### 模型

| 维度 | 分析结论 |
| --- | --- |
| 优先目标 | 不是单次胜利，而是保留或扩大下一步可选行动。 |
| 常见资源 | 情报、稀有物、时间窗口、隐蔽性、可经营的空间。 |
| 典型约束 | 实力阶段、资源消耗、追查风险、环境和灾劫。 |
| 典型动作 | 以短期资源换取未来路径；延后不利事件；把能力转成可重复的经营或分工。 |
| 常见失败模式 | 把信息优势当作绝对确定性，或过度扩张导致维护成本反噬。 |

### 写作诊断

当角色做出看似冷静甚至反常的选择时，补写一句：**他放弃的即时收益是什么，换来的未来选择是什么？** 若答不出来，这个行动可能只是人设标签。

## 模型 B：秩序与传承导向的机构

### 观察基础

- `chapter_26` 以定期补贴和学堂分配表现出组织对成员养成的投入与筛选。
- `chapter_250` 在商队伤亡后呈现货物、士气、伤员和继续生存之间的相互制约。
- `chapter_700` 直接展示组织任务与个人情感之间的冲突。
- `chapter_1900` 呈现高层以议事方式处理研究、资源和政治事务。

### 模型

| 维度 | 分析结论 |
| --- | --- |
| 优先目标 | 延续组织能力、维持成员预期、保护制度的分配权和合法性。 |
| 常见资源 | 人才梯队、规则解释权、存量物资、声望、组织记忆。 |
| 典型约束 | 预算、内部派系、先例效应、成员忠诚、外部威胁。 |
| 典型动作 | 补贴与选拔、正式议事、设定任务、对违例者作出可见回应。 |
| 常见失败模式 | 为了统一口径压制真实问题；把个体当纯工具，低估情感、怨恨与叛离成本。 |

### 写作诊断

机构的每个决定都要同时回答两个问题：**这次能否解决眼前问题？它会给其他成员留下什么先例？**

## 模型 C：威慑与资源点导向的势力

### 观察基础

- `chapter_1400` 显示跨地区势力在损失后需要协调归责、利益与对外反应。
- `chapter_1800` 显示攻击资源点及其后果会改变其他势力的风险评估。
- `chapter_2200` 表明环境/阵法可以让实力差转化为局部优势。
- `chapter_2364` 显示多个顶级行动者并不共享同一个胜利条件。

### 模型

| 维度 | 分析结论 |
| --- | --- |
| 优先目标 | 保住资源网络与谈判位置，防止对手相信自己可以被低成本吞并。 |
| 常见资源 | 底牌、战报/情报渠道、地利、资源点、盟友和报复能力。 |
| 典型约束 | 底牌次数、报复链、错误归因、盟友可靠性、公开信誉。 |
| 典型动作 | 有选择地展示能力；攻击能改变计算的目标；留下模糊性来避免能力边界被完全看穿。 |
| 常见失败模式 | 威慑过度而引发联合反制；只顾外部强硬、忽略内部资源与信任耗竭。 |

### 写作诊断

“大家震惊”不是威慑。至少交代：受众是谁、看到了什么、它据此更新了怎样的损失预期、为什么还没有立即反击。

## 模型 D：条件合作的联盟

### 观察基础

- `chapter_1600` 的战场信息与关键资源让不同阵营暂时形成或调整对抗关系。
- `chapter_2000` 显示身份相近不自动等于利益相同，接触中仍存在轻视、试探与风险。
- `chapter_2300` 显示第三方会在高风险局面中保留行动，等待更有利的窗口。

### 模型

| 维度 | 分析结论 |
| --- | --- |
| 合作基础 | 并非价值观一致，而是短期目标、威胁或收益暂时相容。 |
| 最小承诺 | 合作到什么程度，何时必须交付或分配收益。 |
| 信息问题 | 各方保留的后手、底线与退出条件无法完全验证。 |
| 稳定条件 | 共同威胁仍在；收益分配尚可接受；背叛收益低于合作收益。 |
| 破裂触发 | 威胁消失、收益重新分配、对方能力暴露或可信承诺失效。 |

### 写作诊断

为联盟中的每一方补完条件句：**“只要 ___ 成立，我就继续合作；若 ___ 发生，我就停止支持。”**

## 决策变化的四个旋钮

用以下变量改变一个场景，不需要更换人物性格：

1. **资源存量**：资金/材料从充足变为紧张，最优策略是否变化？
2. **信息可靠度**：情报从确定变为可疑，角色会试探、延迟还是冒险？
3. **退出成本**：撤退是否会失去名誉、领地、同伴或唯一机会？
4. **受众范围**：私下冲突变成公开事件后，组织和联盟要维护什么信号？

## 完整性检查

在分析一场冲突前，检查是否写清：

- 每方的最小可接受结果；
- 每方最害怕的不可逆后果；
- 至少一个可能被误读的公开信号；
- 一个让联盟或计划失效的条件；
- 事件结束后仍会留存的债务、损伤、曝光或先例。
