# 原创策略型长篇：从设定到前 12 章

> 本工作流提炼的是叙事结构，不使用《蛊真人》的人名、世界观名词、情节或文风。目标是帮助你构建一部独立原创作品。

## 总原则

先建立约束，再安排聪明行为。角色的“厉害”应表现为：在已知资源、规则和信息下，他做出了有代价但可解释的选择。

## 第 1 步：一句话系统命题

用下面句式，不超过 60 字：

> 在一个 ___ 是稀缺且可被组织垄断的世界里，一名 ___ 为了 ___，必须在 ___ 与 ___ 之间持续取舍。

示例（原创）：

> 在一个记忆可以提炼为燃料且由城邦征税的世界里，一名抄写员为了赎回被没收的家人记忆，必须在保守秘密与建立盟友之间持续取舍。

检查：若删掉“稀缺物”和“两难取舍”后仍没损失，命题还不够具体。

## 第 2 步：设计资源闭环

不要先设计一百个能力。先设计一条资源如何流动的链：

| 环节 | 你要填写的内容 |
| --- | --- |
| 获取 | 稀缺物如何被发现、生产、继承或抢占？ |
| 转化 | 它如何变成能力、身份、商品或保护？ |
| 消耗 | 使用它的即时成本和长期成本是什么？ |
| 控制 | 哪些机构决定谁有资格获得它？ |
| 风险 | 囤积、交易、使用或展示它会带来什么危害？ |
| 替代 | 有没有较弱但更安全的替代方案？ |

合格标准：主角在前三章就会因这条资源链做出一次不舒服的选择。

## 第 3 步：设定三条硬规则

硬规则必须同时限制主角和对手。推荐从这三类各写一条：

1. **能力规则**：力量如何启动，不能解决什么，失败会怎样。
2. **社会规则**：组织如何登记、征税、惩罚、保护或分配。
3. **信息规则**：哪些知识难以取得、难以验证或暴露后会失效。

反例：主角总能临时获得新能力解决问题。

正例：主角能使用禁术，但每次都会在官方记录中留下可追踪的“回响”。

## 第 4 步：创建四个行动者

按 `ACTOR-SYSTEMS.md` 的一页画布填写，不要写传记。至少包括：

| 角色/势力 | 与主角关系 | 它真正想要什么 | 它无法承受什么 |
| --- | --- | --- | --- |
| 主角 | 自己 | 长期目标与最近目标 | 最小不可逆损失 |
| 机构代表 | 管制/雇佣/保护 | 秩序、资源或合法性 | 坏先例与失控 |
| 对手 | 竞争/阻挡 | 与主角相冲突的合理利益 | 被替代、失去资源或信誉 |
| 条件盟友 | 协作/利用 | 短期共同收益 | 合作收益低于背叛收益 |

每个行动者都要写一条退出或转向条件。

## 第 5 步：用“目标 - 阻力 - 更新”生成冲突

一个有效剧情单元不是“角色打赢了”，而是：

1. 主角提出一个可检验目标。
2. 资源、规则或对手使直线方案不可行。
3. 主角发现一个信息差或创造新选择。
4. 这个动作留下可被追查、利用或报复的痕迹。
5. 对手基于自己的信息集做出合理更新。
6. 结果改变下一单元的资源或关系。

### 冲突卡模板

```md
## 场景标题

- 当前目标：
- 主角拥有的资源：
- 主角不知道的风险：
- 对手的目标与信息：
- 直接方案为什么失败：
- 采用的新选择：
- 即时代价：
- 留下的痕迹：
- 对手下一步合理反应：
- 让下一章发生变化的后果：
```

## 第 6 步：规划第一小卷（12 章）

| 章节 | 任务 | 不能省略的结果 |
| --- | --- | --- |
| 1 | 以压力展示主角的资源缺口与近期目标 | 读者知道“现在不行动会失去什么” |
| 2 | 展示一条硬规则 | 主角或他人因规则付费 |
| 3 | 给出一个看似简单的获取资源方案 | 方案有明确期限或门槛 |
| 4 | 让机构/对手显示不同目标 | 冲突不是误会，而是利益相冲突 |
| 5 | 主角第一次利用信息差 | 信息差有来源且有暴露风险 |
| 6 | 取得局部成果 | 同时损失一项资源或信用 |
| 7 | 对手根据痕迹更新判断 | 对手不需要“全知”也能做合理反应 |
| 8 | 条件盟友出现 | 合作条件与退出条件明确 |
| 9 | 原计划被迫修订 | 新方案比旧方案更贵或更危险 |
| 10 | 主角在资源/关系之间做选择 | 被放弃的一方会留下后果 |
| 11 | 公开或半公开的对抗 | 机构、旁观者或市场开始重新判断 |
| 12 | 达成第一卷目标的一部分 | 下一卷出现更高一级的规则或债务 |

## 第 7 步：验收前 12 章

逐项打勾：

- [ ] 读者能画出资源如何流动。
- [ ] 每个主要行动都有成本、风险或后续责任。
- [ ] 对手至少成功迫使主角修改一次计划。
- [ ] 一次胜利带来新的曝光、债务或敌意。
- [ ] 盟友有独立利益和可理解的退出条件。
- [ ] 第 12 章不是“换地图”，而是旧选择在更大系统里的后果。
- [ ] 世界名词少于解释它们所造成的决策后果。

## 可直接使用的提示词

```text
请用“目标 - 资源 - 规则 - 信息 - 选项 - 代价 - 后果”分析以下原创剧情。
不要模仿任何现有小说的文风或人物。不要把策略写成现实行为建议。

世界设定：
行动者：
本章发生的事：

请输出：
1. 现有冲突的逻辑漏洞；
2. 两种符合各方动机的下一步；
3. 每种选择的持续性代价；
4. 最值得保留的一个信息差。
```

## 常见错误

| 错误 | 症状 | 修正 |
| --- | --- | --- |
| 先堆设定 | 专名很多，但无人因规则被迫改变决定 | 从一项稀缺资源和一次分配冲突开始 |
| 主角总是预判正确 | 悬念只来自读者不知道 | 让信息过期、被污染或引来反调查 |
| 反转否定前文 | 读者回看找不到依据 | 在反转前布置可解释但非显眼的线索 |
| 对手只有恶意 | 任何行动都可用“他坏”解释 | 给对手一项合理利益与一个不能承受的损失 |
| 胜利没有后果 | 每章结束都回到原状 | 让每次胜利改变资源、关系、名声或约束之一 |

## 边界

这是创作与文学分析工具。它不为现实中的欺骗、胁迫、伤害或违法行为提供操作建议。
