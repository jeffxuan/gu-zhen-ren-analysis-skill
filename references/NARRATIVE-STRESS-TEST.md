# 策略叙事压力测试

> 用于检查原创章节、剧情梗概或小卷大纲是否真的由约束推动。该测试不评判文风，也不要求模仿任何既有作品。

## 评分方法

每项给 0-2 分：

- **0 分**：缺失、只能靠作者解释成立，或与前文矛盾。
- **1 分**：存在但模糊，尚未变成实际选择或后果。
- **2 分**：明确影响决策，读者能推导出结果。

总分 20 分。低于 14 分，优先修逻辑，不要急着加世界观名词、战斗或反转。

| 维度 | 要问的问题 | 0 分表现 | 2 分表现 |
| --- | --- | --- | --- |
| 目标清晰 | 本章结束前，谁想得到或避免什么？ | 角色只是在“推进剧情” | 成败条件可观察、可判断 |
| 稀缺约束 | 为什么不能直接达到目标？ | 障碍只是一句“很难” | 资源、规则、时间或风险明确限制方案 |
| 行动选项 | 是否有至少两条可行但有代价的路径？ | 只有作者指定的一条路 | 每条路径都牺牲不同资源或关系 |
| 信息差 | 谁知道得更多或判断错了？ | 反转来自突然补充信息 | 信息有来源、边界与暴露风险 |
| 对手理性 | 对手的决定是否符合其目标和信息？ | 对手只为衬托主角 | 对手能迫使主角重新计算 |
| 成本兑现 | 行动是否消耗了真实资源？ | 胜利无损或立刻恢复 | 代价影响后续章节的选择 |
| 因果痕迹 | 本章是否留下可被追踪或误读的结果？ | 下一章可从零开始 | 结果改变声望、证据、债务或资源分布 |
| 组织反应 | 机构/群体是否有自身利益与先例考量？ | 群体像单一个体 | 决策同时处理眼前收益与未来先例 |
| 升级方向 | 本章是否让问题变得更深而非只更大？ | 只加敌人数值 | 新规则、关系或资源网络进入问题 |
| 原创独立性 | 设定、人物与冲突是否自洽且独立？ | 直接借用已有作品的专名/情节 | 只使用抽象机制，世界与人物自成体系 |

## 诊断路径

### 总分 0-7：先重写冲突骨架

问题通常是“发生了很多事，但没有人被迫选择”。先只写目标、两种方案和各自代价，再补场景。

### 总分 8-13：补信息与后果

问题通常是角色有目标，但行动过于顺利，或对手反应没有依据。添加一个可回溯的信息差和一个跨章节的成本。

### 总分 14-17：可以写正文

逻辑已能支撑戏剧性。写作时保持因果可读，不要用术语替代动作。

### 总分 18-20：检查是否过度设计

高分不等于复杂。检查读者是否能在不看设定表的情况下理解主线冲突，以及是否保留人物的情感、误判和意外。

## 五分钟快速版

当你只想检查一个场景，回答这五句：

1. 主角现在最想要什么？
2. 为什么不能直接拿到？
3. 他放弃了什么来换取机会？
4. 谁会因为这个决定而更新判断？
5. 下一场冲突因此更难在哪里？

若其中任何一句只能回答“因为剧情需要”，就回到 `ORIGINAL-STORY-WORKFLOW.md` 的冲突卡重做。

## 对抗式审稿提示词

```text
你是一名严谨的剧情编辑。请对下面的原创剧情进行压力测试。
不要模仿、续写或引用任何已有小说，也不要提供现实世界的操纵或伤害建议。

剧情：

请按以下十项各给 0-2 分：目标清晰、稀缺约束、行动选项、信息差、对手理性、成本兑现、因果痕迹、组织反应、升级方向、原创独立性。

输出格式：
1. 总分和一句总评；
2. 每项的分数与一句证据；
3. 最严重的两个逻辑漏洞；
4. 每个漏洞给一个最小改动的修复方案；
5. 不新增世界观专名的前提下，给出一个更有压力的结尾。
```

## 示例：如何修一个低压场景

### 初稿

“主角潜入档案馆，轻松拿到禁书，逃走后没人发现。”

### 诊断

- 目标明确，但缺少稀缺约束、可替代选项、信息差成本与持续后果。
- 对手没有合理反应，胜利也没有改变任何关系。

### 最小修复

将禁书改为只能短暂借阅的馆藏；主角可选择留下真实身份记录，或伪造记录而消耗盟友的信誉。无论选择哪一个，档案馆都会在第二天发现异常，只是怀疑对象不同。

这不是把场景变复杂，而是让选择产生不同且持续的代价。

## 使用边界

本量表只服务于虚构创作和文学分析。它不为现实中的规避审查、欺骗、威胁、操控或违法活动提供建议。
